# 纸白微课｜细菌四轮翻倍动画

用一张会动的图，把细菌数量从 1、2、4、8 到 16 的过程讲清楚。

- [下载项目 ZIP](https://github.com/LydiaTools/paper-micro-lesson-workbuddy/raw/refs/heads/main/paper-micro-lesson-workbuddy.zip)
- [飞书实操手册](https://zcnnenrq8yjd.feishu.cn/wiki/K8VuwX28IiWkonkF89BcTFkenFh)

## 怎么用

1. 下载并解压，先打开 `动画工程/index.html` 看首帧。
2. 在 WorkBuddy 加载已安装的 `lemo-opuscar-workbuddy` Skill，把「动画工程」文件夹交给它。
3. 让它读取 `FILM.json` 并按 Skill 的自由编导渲染流程输出横屏 MP4。要换选题，先换变化步骤，再一起改画面与计数。

这个仓库提供本期可编辑动画工程；渲染依赖本地 Skill、Chromium 和 FFmpeg。
